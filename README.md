# Data-Visualization

A comprehensive collection of Jupyter Notebooks demonstrating various data visualization techniques and libraries in Python. This repository serves as a guide and reference for creating static and interactive plots.

## Topics Covered

This repository includes several notebooks, each focusing on specific types of plots and visualization tools:

* **Matplotlib Basics** (`Matplotlib.ipynb`): Fundamentals of creating basic plots, customizing axes, and styling figures using the core Matplotlib library.
* **Categorical Plots** (`Categoricalplots.ipynb`): Visualizing categorical data (e.g., bar plots, count plots, box plots, violin plots).
* **Distribution Plots** (`Distributionplot.ipynb`): Understanding data distributions using histograms, KDE (Kernel Density Estimation) plots, and joint plots.
* **Matrix Plots** (`matrixplot.ipynb`): Exploring correlations and complex data relationships using heatmaps and cluster maps.
* **Regression Plots** (`Regression.ipynb`): Visualizing linear relationships in data using regression lines and scatter plots.
* **Interactive Visualizations** (`plotlyandcufflinks.ipynb`): Creating dynamic, interactive plots using Plotly and Cufflinks.

##  Technologies & Libraries Used

To run the notebooks in this repository, you will likely encounter the following Python libraries:
* **Python 3.x**
* **Jupyter Notebook**
* **Pandas & NumPy** (for data manipulation)
* **Matplotlib & Seaborn** (for static plotting)
* **Plotly & Cufflinks** (for interactive plotting)
